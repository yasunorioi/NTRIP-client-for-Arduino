NTRIP クライアント (M5Atom / M5Stack) 接続マニュアル

RTK 補正データを NTRIP キャスターから受信し、RS232 でレシーバへ流し込む小型機器です。電源を入れて Wi-Fi に接続したあと、ブラウザから NTRIP の接続先を変更できます。

1. 用意するもの

  • 本体 (M5Atom + ATOMIC RS232 Base、または M5Stack + RS232 モジュール)
  • USB-C ケーブル + 5V 電源 (モバイルバッテリー可)
  • Wi-Fi (2.4GHz)。SSID とパスワードを事前に確認しておくこと
  • スマホまたは PC (初回 Wi-Fi 設定および NTRIP 設定変更時)

2. 配線

  • 本体 RS232 端子 ↔ GNSS レシーバの RS232 入力 (TX/RX/GND をクロス接続)
  • USB-C に 5V 電源を接続

3. Wi-Fi 設定 (初回のみ)

  1. 本体に電源を入れる。起動直後 (2秒以内) に本体ボタン (M5Stack は BtnA) を長押しすると設定モードに入ります (M5Atom は LED が 青、M5Stack は LCD に "Config portal active" 表示)。
  2. スマホの Wi-Fi 設定画面で NTRIP-Client を選択して接続 (パスワード不要)。
  3. 自動でブラウザが開きます (開かない場合は http://192.168.4.1 を入力)。Configure WiFi をタップ。
  4. 使いたい Wi-Fi の SSID を選び、パスワードを入力して Save。
  5. 本体が自動的に再起動し、入力した Wi-Fi に接続します。成功すると M5Atom は LED が 緑、M5Stack は LCD に IP アドレスが表示されます。
入力した Wi-Fi 情報は本体に保存されます。次回以降は電源を入れるだけで自動接続するので、毎回この操作は不要です。

4. NTRIP 接続先の設定 / 変更

Wi-Fi に接続できたら、同じ LAN 上のスマホ / PC のブラウザで下記アドレスを開いてください。NTRIP キャスターのホスト・ポート・マウントポイント・ユーザー名・パスワードをその場で変更でき、保存と同時に新しい設定で再接続されます。

本体設定ページ:
http://ntrip-client.local/
QR を読み込むか、ブラウザに直接入力してください。
  • Host: NTRIP キャスターのホスト名 (例: rtk.toiso.fit)
  • Port: NTRIP ポート番号 (一般的には 2101)
  • Mountpoint: マウントポイント名 (例: eniwa-bd982)
  • User / Password: 認証が必要なキャスターの場合のみ入力。不要なら空欄で OK
入力した内容は本体の不揮発メモリ (NVS) に保存されるので、電源を切っても保持されます。ntrip-client.local が解決しない端末では、本体起動時にシリアルに表示される IP アドレスを直接ブラウザに入れてもアクセスできます (M5Stack は LCD にも表示)。

5. LED / 表示の見方

状態M5Atom LEDM5Stack 表示意味 / 対応
起動中 赤"WiFi setup"数秒待つ
Wi-Fi 接続中 黄"Connecting..."1分以上続けば Wi-Fi 設定を見直し
Wi-Fi 設定モード 青"Config portal active"スマホから設定 (上記 3.)
RTCM 受信中 (正常) 緑Status: OK—
データ停滞 (5秒以上受信なし) 虹色Status: STALLED!自動再接続するのでしばらく待つ
NTRIP 設定エラー マゼンタStatus: CFG ERR設定ページ (上記 4.) でホスト / マウントポイント等を確認

6. うまくいかない時

  • 緑にならない / Status が OK にならない: USB を抜き差しして再起動。それでもダメなら Wi-Fi 圏内か、SSID/パスワードを再確認。
  • Wi-Fi 設定をやり直したい: 起動直後にボタン長押し → 設定モードに入り直す。
  • マゼンタ / CFG ERR が出ている: http://ntrip-client.local/ を開いて NTRIP 接続先を確認 (ホスト・マウントポイント・パスワードのタイプミスが多い)。
  • 虹色 / STALLED のまま戻らない: 自動再接続するのでしばらく待つ。頻発する場合は設置場所の電波状況を確認。
  • レシーバが RTK FIX しない: RS232 の配線 (TX/RX が逆になっていないか)、GND 接続、ボーレート (115200) を確認。
